# Estatistica
Análises estatísticas para contextos de negócio. 

# Box Splot
O uso deste visual permite identificar rapidamente a distribuição e concentração dos dados, bem como possíveis outliers em variáveis numéricas. 

# Fonte de dados 
Cidades Brasileiras
Fonte: https://www.kaggle.com/crisparada/brazilian-cities/downloads/brazilian-cities.zip/6

# Colunas disponíveis
Descrição
Tipo de dado

# Posição_IDHM
Descrição: Posição do município no ranking nacional do Índice de Desenvolvimento Humano Municipal (IDHM). Quanto maior o número, melhor a colocação.
Tipo de dado: int

# Município
Descrição: Nome do município analisado.
Tipo de dado: text

# Estado
Descrição: Sigla da unidade federativa (UF) onde o município está localizado.
Tipo de dado: text

# Região
Descrição: Região geográfica do Brasil à qual o município pertence (ex: Norte, Sul, Sudeste, etc.).
Tipo de dado: text

# Qtd municípios
Descrição: Quantidade de sempre igual a 1 para facilitar a análise das dinâmicas construídas.
Tipo de dado: int

# Classificação
Descrição: Faixa de classificação do IDHM do município (ex: Baixo, Médio, Alto, Muito alto).
Tipo de dado: text

# IBGE_1-4
Descrição: Código ou agrupamento definido pelo IBGE, da quantidade de crianças no município de idade 1 a 4 anos.
Tipo de dado: int

# IDHM
Descrição: Índice de Desenvolvimento Humano Municipal geral, que varia de 0 a 1. Quanto maior, melhor o desenvolvimento humano.
Tipo de dado: float

# IDHM_Renda
Descrição: Componente do IDHM relacionado à renda da população.
Tipo de dado: float

# IDHM_Educacao
Descrição: Componente do IDHM relacionado à educação (acesso e qualidade).
Tipo de dado: float

# GDP_CAPITA
Descrição: Produto Interno Bruto per capita do município, em reais. Representa a média de produção econômica por habitante.
Tipo de dado: float

# COMP_P
Descrição: Indicador de quantidade de empresas presentes no município relacionadas à educação.
Tipo de dado: int
